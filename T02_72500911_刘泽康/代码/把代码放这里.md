# Linux常用命令笔记
pwd：查看当前所在文件夹路径，例子：pwd
ls：列出文件夹里文件，ls -la可以查看全部文件，包括隐藏文件和权限信息，例子：ls -la
cd：切换目录，~代表家目录，..代表上一级目录，例子：cd ~/rc_ws
mkdir：创建文件夹，加-p可以一次性创建多层目录，例子：mkdir -p ~/rc_ws/notes
cp：复制文件，复制文件夹需要加-r参数，例子：cp a.py b.py
mv：移动文件，同目录下使用就是重命名，例子：mv old.py new.py
rm：删除文件或文件夹，删除目录需要-r，删除后无法恢复，例子：rm -r temp
cat：一次性查看整个文件内容，适合小配置文件，例子：cat data.yaml
head / tail：head看文件开头，tail看文件末尾，-n可以指定行数，例子：tail -n 20 results.csv
grep：在文件中搜索关键词，-rn递归搜索并显示行号，例子：grep -rn "def ema" .
find：按文件名查找文件，*是通配符匹配任意字符，例子：find . -name "*.py"
echo：在终端输出文字，也可以写入文件，例子：echo hello
sudo：临时获取管理员权限，执行需要权限的操作，例子：sudo apt update
apt：Ubuntu系统软件管理器，用来安装系统程序，例子：sudo apt install -y git
pip / python：pip安装Python库；python执行代码，-c可以运行单行代码，例子：pip install numpy

# 自选额外5条命令（选做加分）
wc：统计文件行数、单词、字符数，例子：wc -l commands.md
chmod：修改文件权限，给脚本增加执行权限，例子：chmod +x run.sh
|管道：将前一条命令输出传给后一条，筛选信息，例子：ls -la | grep py
>重定向：把输出保存到文件，例子：python test.py > log.txt
tee：输出同时打印屏幕并保存文件，例子：python test.py 2>&1 | tee log.txt
